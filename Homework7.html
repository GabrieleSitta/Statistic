Top: (O − E)² / E, the part of χ² coming from that cell (darker = larger). Bottom: the adjusted residual z = (O − E)/√(E(1 − fᵢ·)(1 − f·ⱼ)), which is about N(0, 1) under independence (the simpler (O − E)/√E has a smaller variance, so it underestimates). Independence of events

      
Two events A and B are independent if knowing that one happened does not change the probability of the other:

      
P(A ∩ B) = P(A) · P(B)      equivalently, if P(B) > 0:   P(A | B) = P(A)

      
Independence is not the same as being disjoint: two disjoint events with positive probability are actually dependent, because if B happens then A cannot happen (P(A | B) = 0 ≠ P(A)). For more than two events we need the product rule for every sub-family (mutual independence); pairwise independence is not enough.

    


    

      
Independence of random variables

      
X and F are independent if every event about X is independent of every event about F. For discrete variables this reduces to the joint distribution being the product of the marginals:

      
p(x, f) = p_X(x) · p_F(f)   for all x, f      ⇔      p(f | x) = p_F(f)   for all x

      
So all the conditional distributions of F given X are equal (and equal to the marginal). In general the same holds with the CDFs, F(x, y) = F_X(x)·F_Y(y), or with the densities for continuous variables. Independence implies zero covariance, but not the other way around: Cov = 0 only excludes a linear relation.

    


    

      
Independence in a dataset

      
With data we have frequencies instead of probabilities. X and F are statistically independent in the data when the joint relative frequencies are the product of the marginal ones:

      
fᵢⱼ = fᵢ· · f·ⱼ   ⇔   nᵢⱼ = nᵢ· · n·ⱼ / n   ⇔   all row profiles are equal

      
In a sample this almost never holds exactly, even when the variables are independent in the population, because of random fluctuations. The question is whether the differences between observed and expected counts are too large to be just noise. That is what the χ² test measures.

    


    

      
The χ² test of independence

      
    
        
  • Statistic. χ² = Σ (O − E)²/E sums the squared differences, each scaled by E (for a count, the variance is about its mean). It is 0 exactly when the table is perfectly independent.
    • 
        
  • Distribution. Under H₀ and for large n, χ² is approximately χ² with (r − 1)(c − 1) degrees of freedom: the r·c cells minus the constraints given by the estimated margins (1 for n, r − 1 for the rows, c − 1 for the columns).
    • 
        
  • p-value. The probability, if H₀ is true, of a χ² at least as large as the one observed. If p < α we reject independence. The p-value is not the probability that H₀ is true, and a large p does not prove independence; it only means the data are compatible with it.
    • 
        
  • Conditions. The records should be independent of each other, and the expected counts not too small (the usual rule is E ≥ 5 in all, or at least 80%, of the cells). Otherwise one can merge categories or use an exact or permutation test (tab 4).
    • 
        
  • Strength. χ² grows with n, so it does not measure how strong the link is. Cramér's V = √(χ²/(n(min(r, c) − 1))) is between 0 (independent) and 1 (F completely determined by X, or vice versa).
    •

Association is not causation

      
    
        
  • Confounding. In the example the type of machine influences both variables: servers get the EDR more often and are attacked much more. Ignoring it, the association has the wrong sign (Simpson's paradox).
    • 
        
  • Direction. The χ² test is symmetric in X and F: it says that the variables are linked, not which one influences the other.
    • 
        
  • Chance and multiple tests. With α = 0.05, one test out of 20 rejects a true H₀. If many pairs of variables are tested, some "significant" associations are just noise.
    • 
        
  • Significant is not important. With a lot of data even a tiny difference gives a small p-value (tab 4); Cramér's V and the conditional percentages say whether it matters.
    • 
        
  • What would show causality. A controlled experiment (assigning the EDR at random, so that nothing else can differ between the groups), or at least an analysis that accounts for the confounders, a plausible mechanism and the right time order.
