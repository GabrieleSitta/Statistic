Ex. 1 — Two ways of computing the same area

Riemann: split the x-axis

Σ f(xᵢ) · h

N strips of width h = (b − a)/N; the height of each strip is f at one point xᵢ inside it.

Lebesgue: split the y-axis

Σ yⱼ · μ(Eⱼ)

M levels yⱼ; Eⱼ is the set of x where f(x) falls in level j, and μ(Eⱼ) is its total length.

In practice I don't know the sets Eⱼ exactly, so I estimate their length with 20,000 evenly spread random points in [a, b]: each point counts for a length (b − a)/20,000 and goes into the level of its value f(x). For the Lebesgue result I take the average of the lower sum (each level counted at its bottom) and the upper sum (at its top).

What I observe

  • Accuracy. On smooth functions the Riemann midpoint rule is very accurate: the error goes down like 1/N². For Lebesgue, the gap between upper and lower sum is exactly (level height)·(b − a), so it goes down like 1/M, and on top of that there is the error of estimating the lengths μ(Eⱼ) with a finite number of points.
  • Convergence. For every Riemann-integrable function in the list the two methods approach the same value, as expected from the theory.
  • Cost. Lebesgue needs to know the length of the level sets. Without a formula for them I have to sample the domain anyway (20,000 evaluations of f) and then sort the values into levels, so for the same work Riemann is cheaper and usually more precise on "normal" functions.
  • Robustness. Jumps and wild oscillations hurt Riemann (a strip containing a jump gives an error of order h), while the Lebesgue bound does not depend on continuity at all.

Dirichlet function: 1 on the rationals, 0 on the irrationals

Every interval contains both rational and irrational numbers, so in every strip the sup of f is 1 and the inf is 0: the upper sum is always 1, the lower sum always 0, and the Riemann integral does not exist. On a computer every number is rational, so I treat the two cases explicitly: points like i/N or (2i+1)/(2N) are rational, while a point chosen at random in an interval is irrational with probability 1 (the rationals have measure 0).

For Lebesgue the choice of points does not matter: the set where f = 1 is ℚ ∩ [0, 1], which has measure 0, and the set where f = 0 has measure 1. So the integral is 1·0 + 0·1 = 0.

Thomae function: 1/q at x = p/q, 0 at the irrationals

The function (points p/q with q ≤ 40)

Riemann sums with rational midpoints

Thomae's function is discontinuous only at the rationals, a set of measure 0. By Lebesgue's criterion it is Riemann-integrable, and both integrals are 0: even with only rational points the Riemann sums go to 0, just slowly.

Unbounded and oscillating functions

  • 1/√x on (0, 1] is unbounded, so with left points the first strip uses f(0) = ∞. It only has an improper Riemann integral (limit for ε → 0 of the integral from ε to 1), while for Lebesgue it is a normal integral: μ{f > t} = 1/t² for t ≥ 1, so ∫ f = 1 + ∫₁^∞ t⁻² dt = 2. For this function I use levels 1, r, r², … instead of equal levels.
  • sin(1/x) on (0, 1] (my extra example) oscillates infinitely many times near 0, but it is bounded and has only one bad point, so it is Riemann-integrable. Its integral is sin 1 − Ci(1) = 0.5040670619…

Ex. 2 — The standard normal CDF

Φ(x) = P(Z ≤ x) = (1/√(2π)) ∫₋∞ˣ e^(−t²/2) dt

As in the course notes, the integral exists by comparison with e^(−|t|+1), and with polar coordinates one shows that the total area is 1. As a check, Simpson's rule on [−8, 8] gives …. Because of the symmetry Φ(−x) = 1 − Φ(x), it is enough to compute the integral from 0 to x for x ≥ 0.

Why there is no elementary formula (Liouville)

The integrand has an antiderivative (Φ itself), but it cannot be written with a finite combination of elementary functions. This follows from Liouville's theorem (1835). In the form I need it says: if g and h are rational functions and g·eʰ has an elementary antiderivative, then this antiderivative is R·eʰ for some rational function R. Differentiating:

(R·eʰ)′ = (R′ + h′R)·eʰ = g·eʰ ⇒ R′ + h′R = g

For the Gaussian g = 1 and h = −x²/2, so I would need a rational R with

R′(x) − x·R(x) = 1
  1. R has no poles. If R had a pole of order m at some point, R′ would have a pole of order m + 1 there and x·R only of order m, so the left side would still have a pole. The right side (1) has none, so R must be a polynomial.
  2. No polynomial works. R = 0 gives 0 ≠ 1. If R has degree d ≥ 0, then R′ has degree d − 1 and x·R has degree d + 1, so R′ − xR has degree d + 1 ≥ 1, while 1 has degree 0. Contradiction.

So there is no elementary antiderivative of e^(−x²/2), and Φ has no elementary formula.

The error function

erf(x) = (2/√π) ∫₀ˣ e^(−u²) du substituting t = √2·u: Φ(x) = ½ [1 + erf(x/√2)]

Giving a name to the integral makes the formula for Φ exact. But erf is defined by the same kind of integral, so to get an actual number it still has to be computed numerically: with a series, a continued fraction, a quadrature rule or a fitted approximation. This is what calculators and statistical software do internally.

The course notes give a series, obtained by expanding e^(−t²/2) and integrating term by term:

Φ(x) = ½ + (1/√(2π)) Σₖ₌₀^∞ (−1)ᵏ x^(2k+1) / (2ᵏ (2k + 1) k!)

It is alternating, so the error is at most the first term left out. (Small note: in the PDF the definition of Φ has e^(−t/2) instead of e^(−t²/2), and the z-value should be (x − μ)/σ, not (x − μ)/σ².)

Exercise 1

      
    
      
    For all the Riemann-integrable functions the two approaches give the same value. The difference is in what they need: Riemann needs f to be almost constant on small intervals, Lebesgue only needs to measure the sets where f takes each range of values. That is why Dirichlet's function separates them and why 1/√x is natural for Lebesgue. In practice, for ordinary functions, Riemann-type rules are simpler and cheaper.
    
    
    
    
    
      
    Exercise 2
    
      
      
      
      Φ cannot be written with elementary functions (Liouville). The error function gives an exact formula, but only by naming the integral, so numbers still come from numerical methods. Combining a series near the centre with a continued fraction in the tails gives full double precision everywhere with a few dozen operations, including very small tail probabilities.
